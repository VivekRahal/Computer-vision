# Computer Vision

Computer vision coursework and projects featuring Jupyter notebooks with image processing, feature extraction, and deep learning experiments.

## Contents

| File | Description |
|------|-------------|
| `vivekkumar__singh.ipynb` | Computer vision notebook — image processing and analysis tasks |
| `vivekumarsingh_ipynb.ipynb` | Additional CV experiments and model implementations |

## Topics Covered

- **Image Preprocessing** — Resizing, normalization, augmentation, color space transformations
- **Feature Extraction** — Edge detection, contour finding, histogram analysis
- **Object Detection** — Detecting and localizing objects within images
- **Image Classification** — Categorizing images using CNNs and transfer learning
- **Deep Learning for Vision** — Convolutional Neural Networks, pretrained models (ResNet, VGG, etc.)

## Tech Stack

- **Language:** Python
- **Libraries:** OpenCV, PyTorch / TensorFlow, Torchvision, Pillow, Matplotlib, NumPy
- **Environment:** Jupyter Notebook

## Getting Started

```bash
# Clone the repository
git clone https://github.com/VivekRahal/Computer-vision.git
cd Computer-vision

# Install dependencies
pip install opencv-python torch torchvision pillow matplotlib numpy

# Launch Jupyter
jupyter notebook
```
